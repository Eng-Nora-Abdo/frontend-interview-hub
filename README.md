# بنك أسئلة إنترفيو الـ Frontend 🚀
> تطبيق ويب تفاعلي وعصري لمراجعة أهم أسئلة المقابلات التقنية لمهندسي الواجهات الأمامية (Frontend Developers) باللهجة المصرية والإنجليزية التقنية.

## 🛠️ التقنيات المستخدمة
- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (أيقونات تفاعلية)
- **Cairo Google Font** (خط عربي احترافي)
- **JetBrains Mono** (للأكواد والمصطلحات التقنية)

---

## ✨ المميزات الرئيسية
- 🌐 **واجهة عربية كاملة بنظام RTL:** تدعم اتجاه اليمين لليسار مع الحفاظ على الأكواد والمصطلحات الإنجليزية بالاتجاه الصحيح (LTR).
- 💡 **تقسيم ثنائي ذكي لكل سؤال:**
  - **الفكرة ببساطة:** شرح مختصر ومباشر للمفهوم بالعامية المصرية في صندوق مضيء.
  - **إجابة الإنترفيو:** نقاط محددة واحترافية (`Bullet Points`) يُنصح بذكرها أثناء المقابلة.
- 💻 **أكواد توضيحية مظللة:** أمثلة كود عملية مع زر لنسخ الكود بضغطة واحدة.
- 🏷️ **كلمات مفتاحية تفاعلية:** وسوم للمصطلحات التقنية بالإنجليزية قابلة للنقر والبحث السريع.
- 📊 **شريط تقدم ذكي:** يتتبع نسبة إتقان الأسئلة مع حفظ التقدم محلياً في `localStorage`.
- 🔍 **بحث فوري وفلاتر متقدمة:**
  - بحث في الأسئلة، الشروحات، الكلمات المفتاحية، والأكواد.
  - فلاتر سريعة حسب المواضيع (Variables & Scope, Closures, Event Loop, Async/Await, OOP & Prototypes...).
  - فلتر "الأسئلة المتبقية فقط" للتركيز على ما لم تتم مراجعته بعد.
- 🔄 **إعادة تعيين التقدم:** نافذة منبثقة لتأكيد تصفير الإنجاز للبدء من جديد.

## 🚀 التشغيل محلياً

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
